# Contributing to @noarka/ui

Thanks for your interest. Contributions are welcome.

## Development

```bash
pnpm install
pnpm --filter @noarka/ui build
pnpm --filter @noarka/ui typecheck
pnpm --filter @noarka/ui-docs dev
```

## Guidelines

- Keep changes focused and minimal.
- Follow existing code style (TypeScript, Tailwind v4, Base UI primitives).
- Run `pnpm typecheck` before submitting.
- Add or update docs when adding/changing a component.
- Do not edit `Input.tsx` or `Autocomplete.tsx` unless discussed.

## Pull requests

1. Fork and create a feature branch.
2. Make your changes.
3. Open a PR with a clear description.

## Reporting issues

Open an issue at https://github.com/noarkahq/Noarka/issues.
