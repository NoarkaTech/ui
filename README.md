# Noarka UI

Open-source React component library built on Base UI headless primitives,
styled with Tailwind CSS v4. Dark-first tokens with a light theme.

- **`ui/`** — `@noarka/ui` library source (`src/primitives/*`, design tokens)
- **`ui/docs`** — `@noarka/ui-docs` documentation site (Next.js)
- **`cli/`** — `@noarka/cli` scaffolding CLI (`noarka init`, `noarka add`, `noarka list`)

```bash
pnpm install
pnpm --filter @noarka/ui-docs dev   # docs at http://localhost:3100
```

Published to npm as `@noarka/ui` and `@noarka/cli` (MIT).
